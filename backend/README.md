# Office Wallah Games — Backend

Multi-module Spring Boot backend for Office Wallah Games.

## Tech Stack

- **Java** 21 LTS
- **Spring Boot** 3.4.1
- **Maven** multi-module project

## Modules

| Module   | Description                                    |
|----------|------------------------------------------------|
| `common` | Shared utilities, DTOs, and base configurations |

Game-specific modules will be added under the project as needed.

## Build

```bash
mvn clean install
```
