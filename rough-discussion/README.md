# 📝 Rough Discussion & Dumpyard

This folder serves as an informal workspace for ongoing chat discussions, brainstormed ideas, scratch notes, and temporary working drafts before they are formalized into PRDs or code.

---

## 🎯 Purpose & Behavior
- **Idea Incubator**: All raw thoughts, brainstorming sessions, feature dumps, and chat transcripts go here.
- **Low Ceremony**: Formatting does not have to be strict; can be scratchpads, markdown snippets, or rough drawings.
- **Post-Discussion Extraction**:
  - After alignment in chat/rough notes, the refined plan is converted into a formal PRD in `product_prds/`.
  - The rough notes remain here as historical reference / archive.
- **Safe Dumpyard**: Temporary files, reference schemas, or test payloads can be stored here without polluting the production code folders (`backend/` or `frontend/`).

---

## 📁 Suggested File Formats
- `discussion-<topic>-<date>.md`
- `scratch-<game-name>.md`
- `ideas-backlog.md`
